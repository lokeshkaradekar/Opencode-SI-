# Help, FAQ, and Contact pages

OpenCode SI includes Help & FAQ and Contact & feedback entries in the app menu and links in Settings → About.

## Server wording

The default configuration runs the official OpenCode CLI/server locally through Termux on the Android device. The known local endpoint is `127.0.0.1:4096` when configured for that port. Settings can switch the workspace backend to Remote; therefore the page says "by default" and does not claim every setup is local. The GitHub profile is a maintainer/contact destination, not the server host. Model/provider selection depends on OpenCode configuration.
